# Taste

Taste supplies reusable design judgment to the skills that shape product experiences and interfaces.

- [[taste/README|Taste entry point]] — purpose, boundaries, and progressive-disclosure routing
- [[taste/product-experience|Product experience]] — end-to-end journeys, information architecture, feedback, and recovery
- [[taste/component-contracts|Component contracts]] — reusable component anatomy, behavior, states, composition, and verification
- [[taste/quality-bar|Design quality bar]] — evidence-based critique and completion criteria

Use [[skills/design-pattern/SKILL|design-pattern]] to apply these references. Taste is guidance, not a second skill registry, and never overrides user direction or accepted project decisions.
